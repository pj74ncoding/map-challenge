## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/map-challenge.git
cd map-challenge
```

### Install Dependencies

Frontend:

```bash
cd map-challenge
npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
